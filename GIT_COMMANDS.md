# Sudhir Roy Classes Git Commands

1. git status
2. git add .
3. git commit -m "Update website"
4. git push origin main

---

Single line (PowerShell):
git add . ; git commit -m "Update website" ; git push origin main

Single line (CMD / Git Bash):
git add . && git commit -m "Update website" && git push origin main

---

If rejected / error:
git pull --rebase origin main
git push origin main
